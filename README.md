# Talk Today Teacher Pay Portal

GitHub-hosted prototype for Talk Today USA teacher payroll.

## Current verified data
- 2026-10-01: 15 classes, 201 class-seats, 3,255 MAD
- 2026-10-02: 10 classes, 133 class-seats, 2,205 MAD
- Adnane: 130 MAD/hour

## Payroll rule
- 10 or fewer rostered students: 150 MAD flat per 90-minute meeting
- More than 10: 1.5 × teacher hourly rate

## Important
The current GitHub Pages build is a **demo**, not production authentication. Client-side demo PINs cannot provide genuine teacher privacy.

Production version should use a secure server-side authentication/data layer and enforce teacher authorization there, while continuing to use frozen daily roster snapshots for historical payroll.
